# Grafo de Memoria

El Grafo de Memoria es una representación en red interactiva que muestra cómo las memorias de tu compañera están interconectadas semánticamente.

## Acceso al Grafo de Memoria
Haz clic en el **icono de cerebro** en la esquina superior izquierda de la pantalla principal para abrir el Grafo de Memoria.

## Comprensión de la Visualización

### Nodos (Memorias)
Cada nodo representa un hecho almacenado sobre ti, la relación o experiencias compartidas.

- **Azul**: Datos sobre el usuario (preferencias, antecedentes, atributos).
- **Rosa**: Datos sobre la relación (dinámica entre tú y la compañera).
- **Verde**: Experiencias compartidas (eventos discutidos juntos).

### Conexiones
Las líneas entre nodos indican **similitud semántica**: memorias relacionadas conceptualmente se conectan mediante líneas con partículas animadas.
