# Guía de la Aplicación de Escritorio

La aplicación de escritorio de Luna está construida con Tauri y ofrece características exclusivas de integración con el sistema operativo, incluyendo modo de superposición transparente y atajos de teclado globales.

## Descargas
Puedes descargar los instaladores para tu sistema operativo desde la página de [Descargas](/download) o directamente desde las versiones de GitHub.

- **macOS**: Instalador Universal (`.dmg` o `.app`) para Apple Silicon e Intel.
- **Windows**: Instalador ejecutable (`.msi` o `.exe`) para Windows 10/11.
- **Linux**: Archivo ejecutable `.AppImage` o paquete `.deb`.

## Características Exclusivas de Escritorio

### Modo Superpuesto Transparente (Overlay Mode)
Permite fijar la ventana de tu compañera sobre cualquier aplicación (IDE de código, juegos, documentos).
- La ventana se vuelve flotante y transparente.
- Puedes arrastrarla, cambiar su tamaño o bloquear la interacción según tus necesidades.

### Atajo de Teclado Global
Puedes invocar u ocultar a tu compañera al instante desde cualquier lugar usando la combinación de teclas global configurable.

### Rendimiento Optimizado
Ejecución nativa acelerada por GPU para renderizado Three.js fluido y menor consumo de memoria.

## Configuración y Atajos
- **Alternar Superposición**: `Cmd+Shift+L` (macOS) / `Ctrl+Shift+L` (Windows/Linux).
- **Ajustar Transparencia y Renderizado**: Accesible en el menú flotante o en la configuración de la app.
