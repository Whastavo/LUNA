# Configuración de Speech-to-Text (STT) Local

El reconocimiento de voz te permite hablarle directamente a tu compañera usando tu micrófono.

## Opciones de Reconocimiento de Voz

### Web Speech Recognition API
- **Gratis e integrado**: Utiliza el motor de reconocimiento de voz nativo de tu navegador.
- **Configuración**: En **Ajustes > STT**, activa **Web Speech Recognition**. Concede permisos de micrófono a la aplicación cuando el navegador lo solicite.

### Whisper Local / Servidores de Audio
- Puedes usar Whisper localmente a través de servidores compatibles para una transcripción de voz de alta precisión.
